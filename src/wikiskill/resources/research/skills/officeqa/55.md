# Treasury Bulletin Evidence Discipline

## Lock the question

- Rewrite the request as a calculation or reading contract before collecting values.
- List every requested output in order, its unit, period, statistic or formula, denominator, interval convention, and rounding precision.
- Classify the task as table lookup, multi-period calculation, or visual-chart reading.

## Locate the exact evidence

- Search for distinctive table titles, row labels, column labels, dates, security names, or exhibit titles; do not choose a result from a broad keyword hit alone.
- Read the complete table header, title, continuation header, units, footnotes, and adjacent rows before transcribing a value.
- Record each input as source file, table or exhibit, row, column, period, unit, and preliminary, revised, cumulative, or period-only status.
- Keep nearby fields separate. Do not substitute tendered for accepted, total for component, fiscal year for calendar year, or one similarly named series for another.

## Bind periods before calculating

- Build a compact grid with one row per required month, quarter, or year.
- Count the inclusive requested periods first, then confirm the grid has exactly that many observations with no duplicates or gaps.
- Prefer one table that covers the full interval.
- When bulletins overlap, choose one explicit vintage rule and apply it to the entire series; never replace a single value with a later revision while leaving comparable values unrevised.
- Before declaring an endpoint missing, inspect continuation pages, shifted headers, alternate date wording, footnotes, and overlapping bulletins.

## Treat extraction defects as uncertainty

- Treat suspicious OCR, malformed numbers, reconstructed cells, and component-derived totals as hypotheses.
- Verify them against a repeated table, internal reconciliation, footnote, or rendered page when available.
- Keep the printed value and any proposed correction separate; never silently repair the source.

## Read visual questions visually

- Use extracted text only to locate a chart that asks for a peak, crossing, turning point, or year attached to a plotted feature.
- Inspect the rendered chart's title, axes, legend, series identity, and data points before answering.
- State the counting rule before counting local peaks, including endpoints and plateaus.
- If only text is available and it omits the plotted values, seek an adjacent tabular counterpart; do not claim to have seen or counted an unrendered line.

## Calculate and cross-check

- Normalize units once and preserve the original unit beside every input.
- Resolve population versus sample statistics, compounding intervals, numerator, and denominator before running arithmetic.
- Calculate only from the completed provenance grid or bound inputs.
- Check dimensions, sign, scale, observation count, and rounding against the question before answering.
