# Paper-alignment resources

Prompt transcriptions are drawn from the appendix of **WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution**, Liyan Tang, Cyrus Rashtchian, Chun-Sung Ferng, Andrew Tomkins, Da-Cheng Juan and Tu Vu (2026), [arXiv:2608.27454](https://arxiv.org/abs/2608.27454). Whitespace from the HTML listing is normalized. Attribution to the paper authors is retained; the framework's MIT notice does not claim authorship of their prompt text.

The adjacent Python `wikiskill.paper_alignment` package provides deterministic contracts and evidence helpers. It does not make the default portable CLI a full paper-aligned isolated backend. See the dated research update for the exact shipped/running boundary and operational adaptations.
